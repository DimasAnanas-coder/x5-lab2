# Ответы на сложные контрольные вопросы

### 3 вопрос
Программа не ускорилась, потому что корутины не запускаются одновременно, а каждая ждет предыдущую и только потом запускается. Т.е. запуск в цикле - это последовательный запуск. 

На самом деле время работы программы даже выросло (с 10.00s до 10.09s). Это объясняется тем, что Event Loop тратит время на прерывание и запуск корутин


### 5 вопрос
 Если убрать await перед work(...), то в консоли будет ошибка:
```
RuntimeWarning: coroutine 'work' was never awaited work(i)
RuntimeWarning: Enable tracemalloc to get the object allocation traceback
```
Если вывести в консоль результат корутины work(...), то увидим, что она возвращает сам объект корутины, а не результат функции. По сути ошибка происходит потому, что мы не ждем выполнения корутины, без await она не начинает выполнять находящуюся внутри функцию.
